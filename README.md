# 10.0.0.1 Router Guide

This repository contains beginner-friendly information about the 10.0.0.1 private IP address and basic router administration.

## What is 10.0.0.1?

10.0.0.1 is a private IP address that some routers use as a local default gateway. When supported by the router, users may be able to access an administration page through a web browser.

## 10.0.0.1 Login

To try accessing the router administration page:

1. Connect your device to the router.
2. Open a web browser.
3. Enter `10.0.0.1` in the address bar.
4. Enter the correct administrator credentials if a login page appears.
5. Check your router documentation if the address does not work.

Not every router uses 10.0.0.1. If the page does not open, check your device's network settings to find the actual default gateway.
